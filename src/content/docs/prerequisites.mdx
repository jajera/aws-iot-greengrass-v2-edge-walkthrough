
## Mutation gate

Agents authoring this repo refuse mutating AWS CLI unless
`GG_EDGE_ALLOW_AWS=1` is set. **You** run the walkthrough commands in your own
shell; the gate is for agent sessions. Read-only `describe` / `list` / `get` /
`sts` stay allowed without it.

### Opt in for agent mutations

```bash frame="terminal"
export GG_EDGE_ALLOW_AWS=1
```

```text
(no output)
```

<Aside type="caution" title="Unset gate">
Without it, agent shell jobs stop with a refuse-to-mutate message and change
nothing — deliberate, not an error.
</Aside>

## Cost warning

Things and certs are cheap, and a running Nucleus with{" "}
<Tooltip term="moquette" label="Moquette" /> mostly costs electricity. The AWS
integration pages add usage-billed services: IoT Core messages and rule
actions (two zones at 10 s send about 17,000 telemetry messages a day, each
matched by three rules), S3 requests and storage, DynamoDB on-demand writes, a CloudWatch
custom metric and alarm per zone, CloudWatch Logs ingestion, and a few minutes
of a SageMaker <code>ml.m5.large</code> training job. Check current prices on
the [AWS Pricing Calculator](https://calculator.aws/) for your Region.
[Teardown](/teardown/) removes every resource when you finish.
