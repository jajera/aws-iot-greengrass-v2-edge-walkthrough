## Out of scope

Stream Manager, ESP32 firmware OTA, IoT Analytics, Device Defender, multi-core HA,
Windows cores, Nucleus lite install, SageMaker Edge Manager, Docker components,
console auto-provision as the only install path.

In scope after the local loop: Greengrass cloud deployments from S3, LogManager
→ CloudWatch Logs, IoT rules → S3 / DynamoDB / CloudWatch, SNS → Lambda →
cloud-to-edge commands, and SageMaker-trained ONNX inference on the core. Start
at [Deploy from the cloud](/deploy-cloud/).
