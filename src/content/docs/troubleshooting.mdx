## Useful commands

### Core device status (workstation)

```bash frame="terminal"
aws greengrassv2 get-core-device --core-device-thing-name "$CORE_THING_NAME"
```

```text
{
    "coreDeviceThingName": "gg-edge-wt-dev-core",
    "status": "HEALTHY",
    …
}
```

### Nucleus logs and components (NUC)

```bash frame="terminal"
sudo journalctl -u greengrass -n 100 --no-pager
sudo /greengrass/v2/bin/greengrass-cli component list
sudo tail -n 100 /greengrass/v2/logs/greengrass.log
```

```text
… greengrass.service / component list / greengrass.log …
```
