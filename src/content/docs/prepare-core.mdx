### Rename if already installed as `ubuntu-server`

```bash frame="terminal"
sudo hostnamectl set-hostname nuc-gg-edge
```

```text
(no output)
```

Also update `/etc/hosts` if it still lists `ubuntu-server` (common Subiquity
`127.0.1.1` line).

## Record `NUC_HOST`

### Read hostname and LAN IP (NUC)

```bash frame="terminal"
hostnamectl
ip -br a
```

```text
Static hostname: nuc-gg-edge
…
Operating System: Ubuntu 24.04.5 LTS
…
enp3s0           UP             192.168.1.50/24 …
```

(Interface name varies — on this NUC6CAYB it was `enp3s0`.)

### Set `walkthrough.env` (workstation)

```bash frame="terminal"
NUC_USER=ubuntu
NUC_HOST=192.168.1.50
```

```text
(no output)
```

Use your LAN IPv4 from `ip -br a`, not the sample above.

## Prove SSH (lab env)

```bash frame="terminal"
set -a && source config/walkthrough.env && set +a
ssh "${NUC_USER}@${NUC_HOST}" 'uname -a && lsb_release -ds'
```

```text
Linux nuc-gg-edge 6.8.0-146-generic #146-Ubuntu … x86_64 …
Ubuntu 24.04.5 LTS
```

<Aside type="note">
You do **not** need AWS CLI on the NUC for a manual-provision install. Keep CLI on
the workstation; copy only certs and (later) component files onto the NUC.
</Aside>
