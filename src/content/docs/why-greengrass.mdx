## Tradeoffs

<table>
  <thead>
    <tr>
      <th>Need</th>

## Single point of failure

One <Tooltip term="nucleus" label="Nucleus" /> +{" "}
<Tooltip term="moquette" label="Moquette" /> on one NUC is a SPOF for local MQTT
and for components that decide there. This walkthrough does not build multi-core
HA.

## Nucleus lite

AWS also offers Nucleus lite for constrained hosts. This lab uses **classic
Nucleus** on Ubuntu x86. See the
[developer guide](https://docs.aws.amazon.com/greengrass/v2/developerguide/greengrass-nucleus-lite.html)
if you need lite later.
